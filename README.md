# Описание

Данный проект позволяет создать web-сервис используя язык программирования python и его web-фреймворк flask.

![WordPress Plugin Version](https://img.shields.io/badge/python-latest-green) ![WordPress Plugin Version](https://img.shields.io/badge/flask-latest-green) 

### Подготовка

На компьютере должено быть установлен python. Скачать его можно по [сслыке](https://www.python.org/downloads/).

Для получения копии этого проекта необходимо клонировать проект к себе на машину командой:

    git clone https://github.com/lod2007/flask.git your_project

### Установка окружения для локального запуска Flask 
Для этого выполните команду в терминале:

    python -m venv .venv

Дальше в PowerShell выполните команду:

    .venv\Scripts\Activate.ps1

После успешной активации перед вашим путем в терминале появится префикс (.venv)

Установка непосредственно Flask:

    pip install flask  

### Запуск приложения
В терминале выполните команду:

    .venv\Scripts\python.exe app.py

В браузере перейдите по адресу:
    
    http://127.0.0.1:5000


### Выйти из окружения venv
Для выхода из окруждения venv, выполните команду:

    deactivate

### Описание приложения в парадигме MVC
MVC - модель, вид, контроллер.
Обзор каталогов и файлов проекта: 
 - **models** - находятся файлы моделей. Эти файлы отвечают за выборку и обработку данных.
 - **templates** - находятся файлы шаблонов, которые отображаются через render_template.
 - **views** - находятся файлы видов. Эти файлы отдают нужные данные контроллеру.
 - **app.py** - файл приложения
 - **routes.py** - файл c роутами (марщрутами), и по совместительству кнотроллер: через него работают все остальные файлы.

```    
my_project/
          │
          ├── app.py          # Главный файл запуска приложения
          └── routes.py       # Файл, где будут храниться все маршруты
```
Из файла routes.py можно отдельно вынести код в файл "главного контроллера", в которм уже распределятся пути на конкретный контроллеры приложения (если приложение большое). Или можно описать все в одном файле  routes.py если приложение маленькое.
